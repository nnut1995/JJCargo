> สำหรับเจ้าของและพนักงานที่เพิ่งเริ่มใช้ระบบ · อัปเดต 3 พ.ย. 2026
> เว็บทดสอบ: https://jjtest.nandpmuaythai.com

## 1. ระบบนี้คืออะไร

JJ Cargo คือระบบหลังบ้านของธุรกิจ **ฝากสั่งของจากจีน + ขนส่งจีน → ไทย** เป็นเวอร์ชันเว็บของโปรแกรมเดิม `JJCargoForm.exe` (Windows) ทำได้ครบทุกเมนูของโปรแกรมเดิม แต่เปิดผ่านเบราว์เซอร์ได้จากทุกเครื่อง

ระบบดูแลงาน 4 ส่วนหลัก:

| ส่วน | ทำอะไร |
|---|---|
| **ออเดอร์ / บิลโอน** | จดว่าลูกค้าสั่งอะไรจากร้านจีน, เปิดบิลเพื่อจ่ายเงินให้ร้าน |
| **แพคของ / ขนส่ง** | รับของที่โกดังจีน, แพคเป็นกล่อง, ชั่งน้ำหนัก, ขึ้นตู้, ติดตามสถานะตู้, คิดค่าขนส่ง |
| **ลูกค้า** | ข้อมูลลูกค้า, ยอดเงินคงเหลือ (บาท / หยวน), รายการแจ้งโอน |
| **บัญชี** | ตรวจยอดโอน, รายการเดินบัญชีธนาคาร, ค่าใช้จ่าย, แลกเงิน, สรุปยอดค้างจ่าย |

**ภาษา:** หน้าจอแสดงไทย + จีนพร้อมกันเหมือนโปรแกรมเดิม เปลี่ยนเป็นไทย / จีน / อังกฤษอย่างเดียวได้

## 2. ภาพรวมการทำงานตั้งแต่ต้นจนจบ

```
ลูกค้าสั่งของ ──► [1] เปิดออเดอร์
                       │
                       ├──► [2] เปิดบิลโอน (บิลที่ต้องจ่ายร้านจีน)
                       │          └──► [3] จ่ายบิล → หักจาก Balance เงินหยวนของลูกค้า
                       │
ของถึงโกดังจีน ──► [4] แพคของเป็นกล่อง (PK0001…) + พิมพ์ฉลาก/ใบรับของ
                       └──► [5] ชั่งน้ำหนัก/วัดขนาด (ทำตอนแพค หรือทำทีหลังก็ได้)
                                 │
                                 ▼
                  [6] ขึ้นตู้ (สแกนรหัสกล่องเข้ารอบขนส่ง)
                                 │
                                 ▼
                  [7] อัปเดตสถานะตู้: ขึ้นตู้แล้ว → ระหว่างทาง → ศุลกากร → ถึงโกดังไทย → นำจัดส่ง
                                 │
                                 ▼
                  [8] สรุปยอดค่าขนส่ง → หักจาก Balance ของลูกค้า + พิมพ์บิล
                                 │
ลูกค้าโอนเงิน ──► [9] บันทึกแจ้งโอน ──► [10] บัญชีตรวจยอดกับรายการธนาคาร → อนุมัติ → เงินเข้า Balance
```

**หัวใจของระบบคือ "Balance" (ยอดเงินคงเหลือ) ของลูกค้า** ลูกค้าแต่ละคนมี 2 กระเป๋า:

- **Balance เงินไทย (THB)** — เงินที่ลูกค้าเติมเข้ามา, ใช้จ่ายค่าขนส่ง
- **Balance เงินจีน (CNY)** — ใช้จ่ายค่าสินค้าให้ร้านจีน (จ่ายบิล)

ทุกครั้งที่มีเงินเข้า/ออก ระบบจะเขียนบรรทัดลง Balance ให้อัตโนมัติ ไม่ต้องไปแก้มือ ยอดคงเหลือ = ผลรวมรายรับ − รายจ่ายทั้งหมด

## 3. เข้าสู่ระบบ และหน้าแดชบอร์ด

- เข้าเว็บ → ใส่ชื่อผู้ใช้ + รหัสผ่าน (แอดมินสร้างให้ที่เมนู *ข้อมูลพนักงาน*)
- เปลี่ยนรหัสผ่านตัวเองได้ที่ *ตั้งค่าทั่วไป*
- **แดชบอร์ด** แสดง:
  - **ขั้นตอนงานประจำวัน** — ปุ่มลัด 6 ขั้นตามลำดับงานจริง: เพิ่มออเดอร์ → เปิดบิลโอน → แพคของ → ขึ้นตู้ → สรุปค่าขนส่ง → ตรวจยอดโอน
  - **งานที่รอทำ** — เรื่องที่ค้างอยู่พร้อมจำนวน คลิกแล้วไปหน้าที่ต้องทำต่อทันที (แจ้งโอนรอตรวจ, ของรอแพค, กล่องที่ยังไม่ขึ้นตู้, บิลที่ยังจ่ายร้านไม่ครบ, ค่าขนส่งค้างจ่าย, รายการที่ยังไม่ได้ติ๊ก "ตรวจแล้ว") เรื่องที่เป็น 0 จะถูกพับไว้ใน "ไม่มีงานค้าง"
  - **เปิดล่าสุด** — หน้าที่เราเพิ่งเปิด (จำไว้ในเบราว์เซอร์เครื่องนั้น)
  - ยอดเงินรวมบัญชีไทย / จีน, เรทแลกเงิน, จำนวนลูกค้า และยอดแต่ละบัญชี
  - รอบขนส่งล่าสุด พร้อมสถานะ
  - **เมนูทั้งหมด** — กดเปิดเพื่อดูทุกหน้าที่ผู้ใช้คนนั้นมีสิทธิ์ (แทนเมนูลัดเดิม)

### ใช้งานให้เร็วขึ้น
- **ค้นหาเมนู / ค้นเลข** — กด `Ctrl + K` (Mac: `⌘ + K`) หรือ `/` หรือคลิกช่องค้นหาด้านบน แล้วพิมพ์ชื่อเมนูภาษาไทย จีน หรืออังกฤษก็ได้ ถ้าพิมพ์เลขออเดอร์ / เลขบิล / รหัสสินค้า จะมีตัวเลือก "ค้นหาเลข" พาไปหน้าออเดอร์ + บิลโอนพร้อมคำค้นทันที ใช้ลูกศรขึ้นลง + Enter
- **เมนูข้างพับได้** — คลิกชื่อหมวดเพื่อเปิด/ปิด ระบบจำไว้ว่าเปิดหมวดไหนไว้ หมวดของหน้าที่เปิดอยู่จะเปิดให้เสมอ
- **หัวหน้ากระดาษติดด้านบน** — ชื่อหน้าและปุ่มบันทึกอยู่ด้านบนตลอดแม้เลื่อนลงไป
- **F1 = บันทึก** ในหน้าแพคของ + ชั่งน้ำหนัก และรับของไม่มีบิล (เหมือนโปรแกรมเดิม)
- **ยืนยันก่อนลบ** — ทุกปุ่มลบ / ยกเลิกสรุปยอด / อนุมัติหลายรายการ จะมีกล่องยืนยันบอกว่ากำลังจะทำอะไร กด Esc หรือ "ยกเลิก" ได้
- **ภาษา** — โหมด ไทย + 中文 แสดงภาษาไทยเป็นหลัก ภาษาจีนเป็นตัวเล็กสีจางข้างๆ เปลี่ยนเป็นภาษาเดียวได้ที่ปุ่มเลือกภาษาด้านบน

แต่ละคนจะเห็นเฉพาะเมนูที่ได้รับสิทธิ์ (ตั้งที่ *ตั้งค่าการเข้าถึงเมนู*)

## 4. เมนูออเดอร์ + บิลโอน

ทุกอย่างเรื่องออเดอร์และบิลโอนอยู่ในหน้าเดียว **ออเดอร์ + บิลโอน** มี 2 แท็บ: **ออเดอร์** (เปิดมาเจอแท็บนี้ก่อน) และ **บิลโอนเงิน**
ปุ่ม **เพิ่มออเดอร์** และ **เปิดบิลโอนใหม่** อยู่มุมขวาบนของหน้านี้

**ช่องค้นหา** ด้านบนของทั้งสองแท็บ: พิมพ์เลขออเดอร์ / เลขบิล / ชื่อร้าน / รหัสสินค้า ได้เลย ระหว่างที่มีคำค้น ระบบจะค้นทุกช่วงวันที่ (ไม่ต้องแก้วันที่)
หน้า "ค้นหารายละเอียด" เดิมถูกรวมเข้ามาในช่องนี้แล้ว ลิงก์เก่าจะพามาที่หน้านี้พร้อมคำค้นเดิม

### แท็บออเดอร์
ค้นตามคำค้น / ลูกค้า / วันที่ แสดงความคืบหน้าแต่ละรายการ: สั่งกี่ชิ้น, เปิดบิลแล้วกี่ชิ้น, แพคแล้วกี่ชิ้น, **ยังไม่ได้รับ** กี่ชิ้น
คลิกออเดอร์เพื่อเปิดรายละเอียดเป็นหน้าต่าง (กด Esc หรือ X เพื่อปิด) มีปุ่ม **แก้ไขออเดอร์**, **เปิดบิลโอนจากออเดอร์นี้** และ **เปิดบิลโอนให้ลูกค้านี้**
กด **เปิดบิลโอน** (ในแถวออเดอร์ หรือในรายละเอียด) ระบบจะเติมให้เอง: ลูกค้า, ทุกรายการที่ยังไม่เปิดบิล (จำนวนที่เหลือ + ราคาตามออเดอร์), บัญชีร้านที่เคยโอนให้ร้านนี้ครั้งล่าสุด และมัดจำของออเดอร์ถ้าเป็นบิลแรก แก้ไขได้ก่อนบันทึก
ลบออเดอร์ได้เฉพาะที่ยังไม่มีบิลและยังไม่ได้แพค

### เพิ่มออเดอร์ใหม่
บันทึกว่าลูกค้าสั่งอะไรจากร้านจีน
- เลือกลูกค้า (ค้นด้วย CODE ลูกค้า), ใส่ **เลขออเดอร์** ของร้าน/แพลตฟอร์ม (เช่น เลข Taobao) — ห้ามซ้ำ ถ้าไม่ใส่ระบบจะแสดงเป็น `#เลขที่ระบบ`
- ชื่อร้าน, เบอร์ร้าน, วันที่สั่ง
- รายการสินค้า: รหัสสินค้า, ประเภทสินค้า, ราคาต่อชิ้น (หยวน), จำนวน

### แท็บบิลโอนเงิน
ดูยอดบิล: ยอดรวม − มัดจำ − ส่วนหัก = ยอดที่ต้องจ่าย, จ่ายแล้วเท่าไร, เหลือเท่าไร (กรองจ่ายแล้ว / ยังไม่จ่ายได้)
ในหน้าบิลเพิ่ม **ส่วนหัก/คืนเงิน** รายสินค้าได้ (เช่น ร้านส่งของขาด) และพิมพ์บิลได้

### เปิดบิลโอนใหม่ (บิลจ่ายร้านจีน)
"บิล" = ยอดเงินที่ต้องโอนให้ร้านจีนสำหรับสินค้าในออเดอร์
- เลขบิลออโต้ เช่น `B26110001` (B + ปี + เดือน + ลำดับ)
- เลือกรายการจากออเดอร์ที่ยังเปิดบิลไม่ครบ, ใส่จำนวน/ราคา/มัดจำ
- เลือกบัญชีร้านจีนที่จะโอนให้
- เปิดบิลเกินจำนวนที่สั่งไม่ได้

สิทธิ์ยังแยกเหมือนเดิม (เพิ่มออเดอร์ / ค้นออเดอร์ / เปิดบิล / ค้นบิล) คนที่ไม่มีสิทธิ์ส่วนไหนจะไม่เห็นแท็บหรือปุ่มนั้น

## 5. เมนูแพคของ / ขนส่ง

### แพคของ + ชั่งน้ำหนัก
- เลือกลูกค้า → เห็นรายการที่รอแพค → เลือกสินค้าที่อยู่ในกล่องนี้
- แพคได้ถึงจำนวนที่ **สั่ง** แม้ยังไม่ได้เปิดบิล
- **ไม่ต้องใส่น้ำหนัก/ขนาด/ของข้างใน ก็บันทึกได้** (รับของก่อน ชั่งทีหลัง)
- สร้างทีละหลายกล่องได้ (สูงสุด 200)
- รหัสกล่องออโต้ `PK0001`, `PK0002` …
- หลังบันทึก พิมพ์ **ฉลากกล่อง** (มีบาร์โค้ด + CBM) และ **ใบรับของ** ได้ทันที

### รับของไม่มีบิล
สำหรับของที่ลูกค้าส่งมาเองโดยไม่มีออเดอร์ในระบบ → ระบุแค่ประเภทสินค้า + จำนวน แล้วพิมพ์ใบรับของให้คนมาส่ง

### ชั่งน้ำหนัก / วัดขนาดทีหลัง
ตารางกล่องที่ยังไม่มีน้ำหนัก/ขนาด → กรอกต่อกันหลายกล่องแล้วกดบันทึกครั้งเดียว
(ถ้ากล่องนั้นสรุปยอดค่าขนส่งไปแล้ว ต้องยกเลิกสรุปยอดก่อน)

### แพคจากไฟล์
วางข้อความหรืออัปโหลดไฟล์ รองรับ 2 แบบ:
- แบบเดิม `ShipmentN.txt`: `rowid|ctn|no|PKcode|customerId|CODE|น้ำหนัก|กว้าง|ยาว|สูง|tracking`
- CSV: `CODE,น้ำหนัก,กว้าง,ยาว,สูง,tracking,หมายเหตุ`

ระบบแสดงตัวอย่างก่อนบันทึก (บรรทัดไหนลูกค้าไม่เจอ / กล่องไหนมีอยู่แล้วจะอัปเดต)

### ค้นหา PackingList
ค้นกล่องตามลูกค้า / รอบ / วันที่, แก้น้ำหนัก ขนาด หมายเหตุ, แก้ของในกล่อง, พิมพ์ฉลากซ้ำ
มีมุมมอง **สรุปรายลูกค้า** (จำนวนกล่อง, น้ำหนักรวม, CBM รวม, เลขออเดอร์)

### รอบขนส่ง
- สร้างรอบ (ตู้/รถ) ใส่รหัสรอบและวันที่
- **อัปเดตสถานะ** ตามลำดับ พร้อมประวัติว่าใครเปลี่ยนเมื่อไร:

  | สถานะ | ภาษาจีน |
  |---|---|
  | ขึ้นตู้แล้ว | 已装柜 |
  | อยู่ระหว่างทางขนส่ง | 运输中 |
  | ตู้โดนตรวจที่จีน | 中国查柜 |
  | ตู้โดนตรวจที่ไทย | 泰国查柜 |
  | ทำพิธีศุลกากรแล้ว | 已清关 |
  | ถึงคลังสินค้าที่ไทยแล้ว | 已到泰国仓库 |
  | นำจัดส่งแล้ว | 已派送 |

- ดู/พิมพ์ **รายงาน Packing List** ของรอบ (แยกตามประเภทสินค้า)

### ขึ้นตู้เมืองจีน
เลือกรอบ → สแกนบาร์โค้ดกล่อง (หรือพิมพ์ `PK…`) ทีละกล่อง → กล่องเข้ารอบนั้น
เอากล่องออกได้ ถ้ายังไม่ได้สรุปยอดค่าขนส่งของลูกค้าคนนั้น

### สรุปยอดค่าขนส่ง
เลือกรอบ → เห็นรายชื่อลูกค้าในรอบ + ค่าขนส่งที่คำนวณไว้

**วิธีคิดค่าขนส่ง ต่อกล่อง:**
- CBM (ลบ.ม.) = กว้าง × ยาว × สูง (ซม.) ÷ 1,000,000
- ตามกิโล = น้ำหนัก × เรทกิโล
- ตามคิว = CBM × เรทคิว
- ลูกค้าตั้งได้ว่าคิดแบบ **กิโล / คิว / mix (เลือกอันที่แพงกว่า)**
- แก้เรทรายกล่องได้ (กิโล / คิว / ราคาเหมา)
- เรทลูกค้าไม่ได้ตั้ง → ใช้เรทกลางจาก *ตั้งค่าทั่วไป* (ค่าเริ่มต้น 35 บาท/กก., 5,500 บาท/คิว)
- เพิ่ม **ค่าใช้จ่ายอื่น** (เช่น ค่าตีลังไม้) ได้

กด **สรุปยอด** → ระบบหักค่าขนส่งจาก Balance ลูกค้า และล็อกน้ำหนัก/ขนาด/เรทของกล่องทั้งหมด (แก้ไม่ได้จนกว่าจะยกเลิกสรุปยอด) → พิมพ์บิลค่าขนส่งให้ลูกค้า

### ค้นหารายการค่าน้ำหนัก
ค้นค่าขนส่งที่สรุปแล้วข้ามทุกรอบ ตามลูกค้า / ช่วงวันที่ / จ่ายแล้วหรือยัง

### ประเภทสินค้า
จัดการประเภทสินค้า (ชื่อไทย/จีน/อังกฤษ) และหน่วย (ชิ้น, กล่อง, ม้วน, กิโล, คู่) — กด **+** เพิ่มประเภทใหม่จากหน้าแพคได้เลย

## 6. เมนูลูกค้า

### ข้อมูลลูกค้า
- CODE ลูกค้า (ห้ามซ้ำ), ชื่อ, ชื่อเล่น, โทร, อีเมล
- เรทค่าขนส่งเฉพาะลูกค้า (บาท + หยวน), วิธีคิด (กิโล/คิว/mix), วงเงินเครดิต
- ลูกค้าแม่ (parent) / ผู้แนะนำ
- ที่อยู่จัดส่งหลายที่ (ตั้งที่อยู่หลักได้)
- หน้าลูกค้าเปิดแบบ **อ่านอย่างเดียว** ก่อน ต้องกด *แก้ไข* ถึงจะแก้ได้
- แสดงแยก 3 ยอด: Balance บาท, Balance หยวน, **ค่าขนส่งค้างจ่าย**

### Balance เงินไทย / Balance เงินจีน
รายการเดินบัญชีของลูกค้าพร้อมยอดคงเหลือสะสม
- บรรทัดที่ระบบสร้างเอง (จากแจ้งโอน, ฝากถอน, จ่ายบิล, ค่าขนส่ง) **แก้ไม่ได้ที่หน้านี้** ต้องไปยกเลิกที่ต้นทาง
- เพิ่มรายการเองได้ (เช่น ปรับยอด) — แก้/ลบได้เฉพาะรายการที่เพิ่มเอง

### รายการแจ้งโอน
บันทึกเมื่อลูกค้าแจ้งว่าโอนเงินมาแล้ว ประเภท:

| ประเภท | ผลเมื่ออนุมัติ |
|---|---|
| เติมเงินบาท (`topup`) | เงินเข้า Balance บาท |
| เติมเงินหยวน (`topup_cny`) / ค่าสินค้า (`goods`) | เงินบาทเข้า → แลกเป็นหยวนตามเรท → เงินเข้า Balance หยวน |
| ค่าขนส่ง (`shipping`) | เงินเข้า Balance บาท + ติ๊กว่ารอบนั้นจ่ายค่าขนส่งแล้ว |

จ่ายจาก: โอนเข้าธนาคาร / ตัดจาก Balance บาท / แลกจาก Balance บาทเป็นหยวน

## 7. เมนูฝ่ายบัญชี

### ตรวจสอบยอดโอนเงินลูกค้า
แสดงแจ้งโอนที่รอตรวจ ระบบ **หาบรรทัดธนาคารที่น่าจะตรงกันให้อัตโนมัติ** (บัญชีเดียวกัน, ยอดเงินตรงกัน, วันที่ห่างไม่เกิน ±3 วัน)
- **อนุมัติ** → เงินเข้า Balance ลูกค้า และผูกกับบรรทัดธนาคารนั้น (บรรทัดเดียวใช้ซ้ำไม่ได้)
- หาบรรทัดธนาคารไม่เจอ → อนุมัติได้โดยติ๊ก "อนุมัติโดยไม่มีรายการธนาคาร"
- **ปฏิเสธ** / **รีเซ็ตกลับเป็นรอตรวจ** (ระบบถอนเงินออกจาก Balance ให้เอง)
- คนที่กดได้ต้องมีสิทธิ์ "ตรวจยอดแจ้งโอน" ใน *ตั้งค่าการตรวจสอบ*

### รายการเดินบัญชี
รายการเข้า-ออกของแต่ละบัญชี + ยอดคงเหลือสะสม ค้นหา/พิมพ์ได้
**ยอดบัญชี = ยอดยกมา + ผลรวมรายการทั้งหมด**

### ดึงยอดธนาคาร
วางข้อมูลหรืออัปโหลด CSV ที่ export จากธนาคาร → จับคู่คอลัมน์ (วันที่ / เข้า / ออก / รายละเอียด) → บันทึก
บรรทัดที่ซ้ำกับที่มีอยู่แล้ว (วันที่ + ยอด + รายละเอียดเหมือนกัน) จะถูกข้าม

> **บัญชีเงินสด** (ตั้งเป็น "เงินสด" ในข้อมูลบัญชีธนาคาร) ไม่มีไฟล์ให้ดึง ระบบจะลงรายการให้อัตโนมัติจากค่าใช้จ่าย, ฝากถอน, รายรับอื่น, แลกเงิน, จ่ายบิล
> บัญชีธนาคารจริงต้องดึงยอดเท่านั้น (ระบบไม่ลงให้ เพื่อไม่ให้นับซ้ำ)

### สรุปยอดเงินทั้งหมด
ยอดคงเหลือทุกบัญชี แยกบัญชีไทย / จีน

### ฝาก-ถอนเงิน กวางโจว / เมืองไทย
ลูกค้าฝากหรือถอนเงินสดกับบริษัทโดยตรง (ที่จีน = หยวน, ที่ไทย = บาท) ใส่ค่าธรรมเนียมธนาคาร / ค่าบริการได้ → ระบบลง Balance ลูกค้าให้เอง

### โอนเงินระหว่างบัญชี
ย้ายเงินระหว่างบัญชีบริษัท (เช่น ธนาคาร → เงินสด)

### จ่ายบิล / ค้นหารายการจ่ายบิล
เลือกบิล → ใส่ยอดที่โอนให้ร้าน, บัญชีที่ใช้จ่าย, ค่าธรรมเนียม, ค่าบริการ
- ระบบหัก **ยอด + ค่าบริการ** จาก Balance **หยวน** ของลูกค้า
- ถ้า Balance + วงเงินเครดิตไม่พอ → ระบบไม่ให้จ่าย
- จ่ายครบ → บิลถูกติ๊กว่า "จ่ายครบแล้ว"

### ค่าใช้จ่ายเมืองไทย / เมืองจีน
บันทึกค่าใช้จ่ายรายวันแยกประเภท มีหน้าสรุปตามประเภท และจัดการประเภทค่าใช้จ่ายได้

### รายรับอื่นๆ
รายรับที่ไม่ได้มาจากลูกค้า

### การแลกเปลี่ยนเงิน
- บันทึก **เรทแลกเงินรายวัน** (ใช้เป็นค่าเริ่มต้นตอนอนุมัติแจ้งโอนหยวน)
- บันทึก **รอบแลกเงิน**: แลกหยวนเท่าไร ใช้บาทเท่าไร พร้อมรายการโอนฝั่งไทย/จีน

### สรุปยอดลูกค้าค้างจ่าย
ต่อลูกค้า: ค่าขนส่งค้าง (บาท/หยวน), บิลที่ยังจ่ายร้านไม่ครบ, Balance บาท/หยวนปัจจุบัน — ค้นตามบัญชีร้านจีนได้

### การติ๊ก "ตรวจแล้ว"
ค่าใช้จ่าย, รายรับอื่น, ฝากถอน, โอนระหว่างบัญชี, จ่ายบิล, แลกเงิน — เมื่อหัวหน้าติ๊กตรวจแล้ว **จะแก้หรือลบไม่ได้อีก**

## 8. เมนูตั้งค่า

| เมนู | ใช้ทำอะไร |
|---|---|
| ข้อมูลบัญชีธนาคาร | บัญชีบริษัท: ชื่อ, เลขบัญชี, **บัญชีไทย/จีน**, ยอดยกมา, เป็นเงินสดไหม, ให้ลูกค้าเห็นไหม |
| ข้อมูลพนักงาน | เพิ่มพนักงาน, ตำแหน่ง, ชื่อผู้ใช้/รหัสผ่าน, ปิดการใช้งาน, ดู **log การทำงาน** ของทุกคน |
| ตั้งค่าการเข้าถึงเมนู | เลือกว่าแต่ละ **ตำแหน่ง** หรือแต่ละ **คน** เข้าเมนูไหนได้ |
| ตั้งค่าการตรวจสอบ | เลือกว่าใครมีสิทธิ์ติ๊ก "ตรวจแล้ว" ในเรื่องไหน |
| ตั้งค่าทั่วไป | เรทค่าขนส่งกลาง, ข้อความหัวบิล, การพิมพ์หลังแพค, webhook ส่งสถานะไปเว็บลูกค้า, เปลี่ยนรหัสผ่าน |

แอดมิน (`is_admin`) เข้าได้ทุกเมนูและตรวจได้ทุกเรื่อง

> **หมายเหตุ:** เมนูใหม่ "ชั่งน้ำหนัก / วัดขนาดทีหลัง" ต้องไปเปิดสิทธิ์ให้ตำแหน่งที่มีอยู่แล้วเองที่ *ตั้งค่าการเข้าถึงเมนู*

## 9. คำถามที่พบบ่อย

**แก้ Balance ลูกค้าไม่ได้?** — บรรทัดนั้นมาจากหน้าอื่น ให้ไปยกเลิกที่ต้นทาง (เช่น รีเซ็ตแจ้งโอน, ลบรายการจ่ายบิล, ยกเลิกสรุปยอดค่าขนส่ง)

**แก้น้ำหนักกล่องไม่ได้?** — ลูกค้าคนนั้นในรอบนั้นสรุปยอดค่าขนส่งไปแล้ว → ยกเลิกสรุปยอดก่อน (ทำไม่ได้ถ้าติ๊กว่าจ่ายแล้ว)

**ลบกล่องไม่ได้?** — กล่องขึ้นตู้แล้ว → เอาออกจากตู้ก่อน

**แก้/ลบรายการบัญชีไม่ได้?** — รายการถูกติ๊ก "ตรวจแล้ว"

**จ่ายบิลไม่ได้ ขึ้นว่ายอดไม่พอ?** — Balance หยวนของลูกค้า + วงเงินเครดิต น้อยกว่ายอดที่จะจ่าย → ให้ลูกค้าเติมเงินหยวนก่อน หรือเพิ่มวงเงินเครดิต

**พิมพ์ฉลากยังไง?** — ระบบเปิดหน้าพิมพ์ในเบราว์เซอร์ เลือกเครื่องพิมพ์ฉลาก (เช่น POSTEK) ในหน้าต่างพิมพ์
